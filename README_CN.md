# 补充代码1：蛋白组与代谢组分析

本包提供心脏蛋白组及心脏、血清和尿液代谢组的 R 分析代码、九个处理后定量数据工作簿、软件版本清单和通路注释缓存。图表和分析结果由代码运行生成，不预先附在本包内。文章中可使用的代码可用性声明见 `文章用代码说明.txt`。

## 运行

使用 R 4.4.3、Bioconductor 3.20。依赖版本见 `config/package_versions_target.tsv`。源码安装需要编译工具；Windows 使用 Rtools44，Linux 使用 C/C++/Fortran 编译器。建议使用独立 R 库。

完整解压本包，进入含 `run_all.R` 的文件夹，在终端依次执行以下命令。九个输入文件已放在 `input/` 对应目录，不需要另行下载或移动：

```bash
Rscript install_packages.R
Rscript validate_setup.R
Rscript run_all.R
```

首次安装依赖需要联网。limma 3.62.1 的原始源码包已附在 `vendor/`，安装时核对 MD5。为保持通路注释一致，本包仅附带本次使用的 KEGG 映射缓存，位于 `outputs/enrichment/mapping_cache/`；其余结果由代码生成。

## 分析范围

心脏蛋白组和心脏、血清、尿液代谢组分别分析。雌性与雄性分开，每个性别进行三个年龄比较，合计24个独立两组 limma 比较。差异阈值为 BH 校正后 P < 0.05 且绝对 log2 倍数变化不小于 log2(1.5)。代码生成24个火山图面板和4个集合交集面板，并提供功能富集及蛋白与代谢物相关网络分析。

蛋白输入为蛋白层的 log2 定量值，不再次取对数、标准化或填补。代谢物输入为代谢特征层的线性定量值，非正值转为缺失，正值取 log2，不填补缺失值。每个比较要求每个特征在两组中各有至少两个有效观测值。工作簿中的既有 P 值与差异标签不参与建模。

相关网络按性别分别计算，将同一性别的三个年龄组样本合并，并按动物编号及组别匹配蛋白和代谢物定量值。连线要求完整配对样本不少于5个、Pearson 相关系数绝对值不小于0.60且 BH 校正后 P < 0.05；相关关系不代表直接作用，也不能排除年龄差异的影响。本代码未检验性别与年龄的交互作用。

## 文件与检查

- `config/config.R`：分组、比较方向和分析参数。
- `R/`：按编号排列的导入、分析、作图、导出及检查函数。
- `CODEBOOK.md`：分组映射和结果字段含义。
- `INPUT_MD5SUMS.tsv`：九个研究输入文件的校验值。
- `tests/`：文件名映射和零行交集表的回归检查。
- `validation/`：此前运行使用的 R 环境及软件包版本记录。
- `PACKAGE_SHA256SUMS.tsv`：本包文件的 SHA-256 校验值，清单本身除外。

程序完成时输出 `Completed successfully`。结果写入 `outputs/`，其中 `QC/QC_summary.csv` 应为 PASS；实际 R 环境和包版本写入 `outputs/reproducibility/`。空差异集合是允许的结果，不因空集合放宽统计阈值。

如需单独检查文件名和空交集处理，可在本包根目录运行：

```bash
Rscript tests/test_import_filenames.R
Rscript tests/test_empty_membership.R
```

若 `validate_setup.R` 报告缺文件、输入校验值不符或软件版本不符，应先核对解压目录、原文件和依赖安装情况，确认通过后再运行分析。请勿直接修改输入工作簿后继续沿用原校验清单。

本代码从处理后的定量工作簿开始，不包含原始质谱文件及其鉴定和定量步骤。包内数据不等同于原始质谱数据存储库提交材料。
